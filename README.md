# Aura Properties — Website Handover Package

This is a real, responsive static website (HTML/CSS/JS), not a screenshot.

## Design
Built to closely follow the supplied reference: navy/white/gold palette, slim contact bar, clean navigation, large property hero, featured property cards, About section, services, Why Us, contact CTA, and dark footer.

The website uses original AI-generated real-estate imagery created for this project. The user's Google Maps screenshots are NOT used as website images.

## Hosting
